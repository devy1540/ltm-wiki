# Query Workflow

Query is read-only.

1. Use only the resolved `projectRoot`. Never search the parent Vault's other
   projects or shared notes.
2. Read `wiki/index.md` and search wiki titles, statements, evidence, and aliases
   for the question.
3. Open the smallest useful set of source notes, topics, and syntheses.
4. Read reconciled claims from topic pages, then follow only evidence targets that
   pass the canonical `sources/` path boundary. Verify important, disputed, stale,
   or surprising claims against those sources. Do not treat one wiki page as
   independent confirmation of another.
5. Separate sourced facts, derived conclusions, disagreements, and evidence gaps.
6. Answer with links to the supporting wiki claim and underlying source locator.
7. If evidence is insufficient, say so and identify the searched scope or missing
   source rather than guessing.
8. If the answer creates a durable new comparison or synthesis, propose a title,
   destination, and input claims. Do not write it without explicit approval.

Do not scan every raw source before consulting the accumulated wiki. Raw sources
are verification material, not the default query index.
