# Crystallize Workflow

Crystallize preserves a durable conclusion from an approved analysis or query.

1. Use only the resolved project root; cross-project synthesis requires a separate
   explicit request and is not part of this workflow.
2. Require an explicit crystallize request or approval of a previously proposed
   title, destination, and scope.
3. Search existing syntheses and topics before creating a page.
4. Represent each durable conclusion as a `derived` claim.
5. Link `Derived from` to the input claim anchors and retain their source evidence.
6. Preserve disagreements and limitations; do not turn an unresolved dispute into
   a single conclusion.
7. Update related topic pages when the synthesis materially changes their current
   understanding.
8. Update `wiki/index.md` and append a `crystallize` entry to
   `wiki/operations.md`.
9. Show the changed files and evidence chain.

Do not store a generic conversation summary. Store only the reusable knowledge the
user approved.
